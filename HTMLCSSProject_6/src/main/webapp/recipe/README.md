# Recipe World - Reference Style UI

업로드된 레퍼런스 이미지의 레이아웃 방향을 기준으로 만든 정적 UI 시안입니다.

- recipe/list.html : 메인
- recipe/detail.html : 레시피 상세
- recipe/mypage.html : 마이페이지
- recipe_admin/dashboard.html : 관리자 대시보드
- assets/style.css : 공통 디자인

Bootstrap 없이 순수 HTML/CSS로 구성했으며, Spring Boot + Thymeleaf로 옮기기 쉽도록 페이지를 분리했습니다.

# IT EDU - Reference Style

업로드해주신 Recipe World 레퍼런스의 **레이아웃/밀도/카드형 UI 흐름**을 교육센터 서비스에 맞게 적용한 정적 화면입니다.

## 화면
- main/index.html : 교육센터 메인
- course/detail.html : 교육과정 상세
- exam/list.html : CBT 시험센터
- exam/take.html : 온라인 시험 응시 + 타이머
- mypage/index.html : 마이페이지 (시험점수/오답노트/AI 문제요약/성취도)
- admin/index.html : 관리자 대시보드 (학생/시험/AI출제/취업)

## 디자인 방향
화이트 카드 + 블루 포인트 + 대형 Hero + 카테고리 아이콘 + 인기 과정 카드 + 관리자 다크 사이드바.
Spring Boot + Thymeleaf/Vue로 변환하기 쉬운 페이지 분리 구조입니다.
